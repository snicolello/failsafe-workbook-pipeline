# Failsafe Workbook Pipeline

**FWP** is a personal, public recruiting project. It demonstrates how to keep a work-in-progress report available when source teams change their Excel workbooks. Sedgewater Outfitters, its brands, its teams and every workbook are fictional. All implementation and examples were written for this repository.

The unit of acceptance is one brand and worksheet. The five-field agreement, source coordinates, decision history and report view define what a reviewer can verify locally. The project owner approves profile meaning and public scope. Changes that require new parser behavior receive a regression fixture and a linked pull request.
