# Working in this repository

Start with [PROJECT.md](PROJECT.md) for the project boundaries and [STATE.md](STATE.md) for the verified baseline. GitHub issues own workflow status. Keep the public code, workbooks, examples and review excerpts independently authored and synthetic.

Use the shared parser for layout behavior and one profile per brand. A candidate row must carry a source locator for every core field. Extend an acceptance rule with a real Excel fixture covering the positive and ambiguous cases. Run the full suite before merging a parser or acceptance change.

Human approval is required for adopting new field meanings and brand profiles. Record the proposed diff, before-and-after replay and decision. Optional model commentary cannot write accepted rows or approve a profile.
